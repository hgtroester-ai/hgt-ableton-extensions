## Audio assets

The current releases use 37 embedded MP3 audio payloads derived from **Phazite Sounds**. The supplied project manifests and sound documentation declare these sound assets under **CC0 1.0 Universal**. HGT records the source and license for transparency.

No Toontrack/EZdrummer audio recordings, samples, presets or software are included in the current audio assets. Toontrack/EZdrummer may be named only where relevant as a MIDI mapping compatibility option. This is a technical note-mapping reference, not an audio asset, endorsement or affiliation.

## Artwork

The HGT logos and visual elements are original HGT artwork. Their geometric visual language is inspired by Piet Mondrian; they are not reproductions of Mondrian artworks.
